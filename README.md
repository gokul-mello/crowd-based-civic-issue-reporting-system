# CivicConnect – Smart Civic Issue Reporting System

A full-stack, crowd-based civic issue reporting platform with **AI-assisted grievance structuring**, **community upvoting**, **automated priority scoring**, and **dedicated government authority administration**.

---

## 🌟 Key Features

1. **Dual Role Architecture (Strict Security Segregation)**
   - **Citizens**: Register, login, report issues in everyday language, edit AI-suggested grievances, track resolution lifecycles, and cast community upvotes.
   - **Government Authorities**: Protected access via separate login portal, triage incoming grievances, assign municipal engineering departments, override priority with mandatory justifications, update statuses, and log resolution notes with audit trails.

2. **AI Complaint Generation & Heuristic Fallback**
   - Transforms informal citizen complaints (e.g., *"The road near our bus stop has many big holes..."*) into official, structured civic petitions without fabricating facts.
   - Transparently indicates whether results were generated by Google Gemini AI or the offline rule-based heuristic NLP engine (guaranteeing 100% functionality even when offline or without an API key).
   - Citizen approval workflow: citizens can review and modify the AI grievance before submitting.

3. **Duplicate Detection Engine**
   - Token-similarity (Jaccard similarity) and Geolocation distance checks (Haversine formula).
   - Identifies active complaints in the same locality and allows citizens to upvote existing issues rather than fragmenting complaints.

4. **Transparent Multi-Factor Priority Scoring**
   - Dynamic 0–100 score calculating:
     - Category hazard weights (e.g., live electrical wires, open drainage, deep potholes).
     - Logarithmic community vote impact.
     - Aging factor (older pending grievances automatically gain urgency).
     - Safety urgency modifiers.

5. **Community Voting**
   - Guaranteed one vote per authenticated citizen per complaint (enforced by a MongoDB compound unique index).
   - Prevents citizens from voting on their own complaints.
   - Citizens can add or withdraw their vote at any time.

6. **Interactive GIS Mapping**
   - Pinpoints issues on interactive **Leaflet & OpenStreetMap** maps with latitude/longitude coordinates.

7. **Municipal Analytics Dashboard**
   - **Chart.js** data visualizations depicting complaints by category, lifecycle status distribution, and priority levels.

## 🛠️ Technology Stack

### Frontend
- **React 18** with **Vite**
- **Tailwind CSS** (Navy Blue `#072849` & Teal `#0d9488` civic tech palette)
- **React Router DOM v6** (Role-based route protection)
- **Leaflet & React-Leaflet** (Interactive maps)
- **Chart.js & React-Chartjs-2** (Analytics charts)
- **Axios** (JWT interceptor client)
- **React Icons** & **Framer Motion**

### Backend
- **Node.js** & **Express.js** (REST API)
- **MongoDB** & **Mongoose** (Full schema models, validation, and compound indexes)
- **JWT (JSON Web Tokens)** & **bcryptjs** (Password hashing)
- **Multer** (Photographic evidence upload)
- **Express Rate Limit** (Anti-abuse protection)

## ⚙️ Environment Variables Setup

### 1. Backend (`backend/.env`)

Create `backend/.env` (or copy from `backend/.env.example`):

```env
PORT=5000
MONGODB_URI=mongodb://127.0.0.1:27017/civicconnect
JWT_SECRET=civicconnect_super_secret_jwt_key_2026_secure
JWT_EXPIRES_IN=7d

# AI Configuration (Optional: Leave blank to use built-in heuristic NLP)
AI_API_KEY=
AI_PROVIDER=gemini

# Authority Account Setup Credentials
AUTHORITY_SETUP_EMAIL=admin@civicconnect.gov.in
AUTHORITY_SETUP_PASSWORD=Admin@Civic2026!
AUTHORITY_SETUP_NAME=Municipal Chief Commissioner

FRONTEND_URL=http://localhost:5173
```

> **Note on MongoDB**: If you have a local MongoDB server or a free MongoDB Atlas URI, specify it in `MONGODB_URI`. If MongoDB is not running locally, the system automatically runs an embedded engine for seamless zero-config local evaluation.

### 2. Frontend (`frontend/.env`)

Create `frontend/.env` (or copy from `frontend/.env.example`):

```env
VITE_API_URL=http://localhost:5000/api
```

## 🚀 Installation & Running

### Step 1: Install Dependencies

```bash
# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

### Step 2: Seed Demo Data & Authority Account

From the `backend` folder:

```bash
# Populate realistic demo complaints, civic departments, and accounts
npm run seed
```

Or generate only the government authority administrator:
```bash
npm run create-authority
```

### Step 3: Run the Application

In terminal 1 (Backend):
```bash
cd backend
npm start
```
*Backend runs on `http://localhost:5000`*

In terminal 2 (Frontend):
```bash
cd frontend
npm run dev
```
*Frontend runs on `http://localhost:5173`*

## 🛡️ Security Highlights
- Passwords salted with bcrypt (10 rounds).
- Authority accounts cannot be registered via public registration forms.
- Role-based authorization checked on all `/api/authority/*` routes.
- Rate limiting on authentication and AI generation endpoints.
- Compound unique index on MongoDB votes prevents duplicate voting.
- File uploads filtered to images only (max 5MB).
- Mandatory resolution notes required to resolve complaints; mandatory rejection reasons required to reject complaints.
